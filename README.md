# نبض — تطبيق اختبارات عربي بالذكاء الاصطناعي

نسخة MVP جاهزة للتجربة فورًا: الطالب يكتب اسمه، يحل اختبارات اختيار من متعدد وصح/خطأ، يرى التصحيح، ثم يظهر أفضل ترتيب له. لوحة المدرّس تنشئ مسودات عبر Google Gemini وتنشر الاختبارات بعد المراجعة.

## التشغيل الآن

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`. لا تحتاج إلى قاعدة بيانات أو مفاتيح؛ يوجد اختباران جاهزان وتُحفظ البيانات في `localStorage` داخل المتصفح. رقم دخول المدرّس التجريبي هو `1234`.

## تفعيل Gemini

1. انسخ `.env.example` إلى `.env.local`.
2. ضع مفتاح Google AI Studio في `GEMINI_API_KEY`.
3. غيّر `NEXT_PUBLIC_ADMIN_PIN` قبل مشاركة التطبيق.
4. أعد تشغيل `npm run dev`.

يعمل المفتاح على السيرفر فقط ولا يُرسل للمتصفح. الموديل قابل للتغيير من `GEMINI_MODEL`. كل ناتج AI يمر عبر JSON Schema ثم Zod، ويُحفظ كمسودة غير منشورة حتى يراجعه المدرّس.

## التحقق

```bash
npm test
npm run typecheck
npm run build
```

## حدود النسخة السريعة

- التخزين محلي لكل متصفح، لذا الترتيب غير مشترك بين الأجهزة.
- رقم دخول المدرّس حماية تجريبية وليس نظام حسابات إنتاجيًا.
- لنشر حقيقي متعدد المستخدمين، الخطوة التالية هي نقل الاختبارات والمحاولات إلى Supabase وإضافة Supabase Auth للمدرّس مع إبقاء تجربة الطالب بلا حساب.
