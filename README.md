# نبض — تطبيق اختبارات عربي 

تطبيق Next.js لإنشاء وإجراء الاختبارات (MCQ وصح/خطأ) باللغة العربية. يتضمن التطبيق واجهة الطالب لإجراء الاختبارات، ولوحة للمدرّس لرفع الاختبارات بصيغة JSON ومعاينتها قبل نشرها.

## التشغيل في وضع التجربة (Demo)

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`. لا تحتاج إلى قاعدة بيانات أو مفاتيح للتشغيل في الوضع المحلي؛ سيتم توفير اختبارات جاهزة وتُحفظ البيانات في `localStorage` داخل المتصفح. رقم دخول المدرّس التجريبي هو `1234`.

## تفعيل قاعدة البيانات (Supabase)

لنشر حقيقي متعدد المستخدمين، يدعم التطبيق التخزين السحابي عبر Supabase:

1. أنشئ مشروعًا جديدًا في [Supabase](https://supabase.com/).
2. شغّل أوامر SQL الموجودة في ملف `supabase-schema.sql` في محرر SQL الخاص بـ Supabase لإنشاء الجداول والقيود المطلوبة.
3. انسخ `.env.example` إلى `.env.local`.
4. ضع الرابط ومفتاح `service_role` في `SUPABASE_URL` و `SUPABASE_SERVICE_ROLE_KEY`. (ملاحظة: هذا المفتاح يعمل على الخادم فقط ولا يُرسل للمتصفح).
5. غيّر `ADMIN_PIN` قبل مشاركة التطبيق لحماية لوحة المعلم.
6. أعد تشغيل `npm run dev`.

## رفع الاختبارات (JSON)

تعتمد لوحة المدرّس على رفع ملفات JSON بصيغة محددة. مثال:

```json
{
  "title": "اختبار المجموعة الشمسية",
  "unit": "الفضاء",
  "description": "اختبار مبسط",
  "durationMinutes": 5,
  "questions": [
    {
      "type": "mcq",
      "text": "ما أكبر كواكب المجموعة الشمسية؟",
      "options": ["الأرض", "المشتري", "المريخ", "زحل"],
      "correctIndex": 1,
      "explanation": "المشتري هو أكبر الكواكب."
    }
  ]
}
```
